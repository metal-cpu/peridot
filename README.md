A content-based Balatro mod that adds 21 new Jokers!

Please take a look at the [wiki](https://github.com/metal-cpu/peridot/wiki) while you are here!

# Dependencies
- [Steamodded](https://github.com/Steamodded/smods) (Required)

# Jokers
A total of 21 Jokers!
  * 7 Common, 7 Uncommon, and 7 Rare

Go [here](https://github.com/metal-cpu/peridot/wiki) for more details on them.

| Common         |   | Uncommon          |   | Rare          |
|:---------------|:-:|:------------------|:-:|:--------------|
